	Geografiske Fagdata i GeoDanmark (GeoFA) er en frivillig samling af fællesoffentlige data, som vurderes at have værdi på tværs af kommunegrænser – både for myndigheder og andre eksterne anvendere. Det er frivilligt for myndigheder at benytte databasen til opbevaring og udstilling af data – dermed kan nogle data være ufuldstændige. Data er gratis for tredjepart at hente og anvende lokalt.

	Pluginet giver adgang til alle GeoFA's 80 datasæt i QGIS med samme grupper, navne, felter og kodelister som GeoFA-specifikationen og med symboler som i GeoFA's webkort. Lagene tilføjes fra GeoFA-panelet, hvor man sætter hak ved de lag, man vil have, fra menuen GeoFA eller fra QGIS' søgefelt.

	Uden login viser lagene de objekter, der er offentlige. Med et GeoFA-login (kommuner og andre myndigheder) ser man også de objekter, der ikke er offentlige, og kan redigere sine egne data (WFS-T). Adgangskoden gemmes i QGIS' adgangskodelager, ikke i projekter eller indstillinger.

	Felter med kodelister vises som rullelister, og værdierne hentes direkte fra GeoFA. Når man vælger en kodeværdi (fx oprindkode), udfylder GeoFA selv den tilhørende tekst (fx oprindelse), når der gemmes.

	Man kan vælge kun at se objekter i én kommune. Fotos og GPX-spor åbnes som links i browseren. Testmiljøet kan vælges i indstillingerne; lag derfra får »[TEST]« i navnet.

	Hvis man mangler sit login eller skal oprettes som ny bruger, bedes man sende en mail til support@geopartner.dk med emnet ”GeoFA brugeroplysninger”.

	English Version:

	Geographical Professional Data in GeoDanmark (GeoFA) is a voluntary collection of joint public data, which is considered to have value across municipal boundaries - both for authorities and other external users. It is voluntary for authorities to use the database for storage and display of data - thus some data may be incomplete. Data is free for third parties to download and use locally.

	The plugin gives access to all 80 GeoFA datasets in QGIS, with the same groups, names, fields and code lists as the GeoFA specification and with symbols as in GeoFA's web map. Layers are added from the GeoFA panel, by ticking the layers you want, from the GeoFA menu or from QGIS's search bar.

	Without a login the layers show the objects that are public. With a GeoFA login (municipalities and other authorities) you also see the objects that are not public, and can edit your own data (WFS-T). The password is kept in QGIS's password store, not in projects or settings.

	Fields with code lists are shown as drop-down lists, with the values read directly from GeoFA. When you choose a code value (e.g. oprindkode), GeoFA fills in the matching text (e.g. oprindelse) itself when the object is saved.

	You can choose to see only the objects in one municipality. Photos and GPX tracks open as links in the browser. The test environment can be chosen in the settings; layers from it get "[TEST]" in their name.

	If you are missing your login or need to be created as a new user, please send an email to support@geopartner.dk with the subject "GeoFA brugeroplysninger".
